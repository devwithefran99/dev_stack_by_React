# Ques 02 : What is the difference between props and state?

# Ques 05 :  Why does every item in a .map() list need a unique key prop?
ans : A unique "key" helps React identify each item in a list. It allows React to update the list efficiently when the data changes.

# Ques 06 : What is conditional rendering? Show one place you used it (example: the empty stack message).
Ans : Conditional rendering means showing different content based on a condition. I used it to show an empty stack message when there are no items in the list.

# Ques 07 :How do you pass data from a parent component to a child component, and how does a child send something back to the parent?
ans:  A parent sends data to a child using props. a child can send data back to the parent by calling a function through props.
